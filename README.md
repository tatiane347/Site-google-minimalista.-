Meu Projeto: Página de Busca Google Minimalista (HTML, CSS e JavaScript) 🚀
Olá, pessoal! 👋
Compartilho com vocês o desenvolvimento de uma página de busca do Google minimalista, construída utilizando as tecnologias fundamentais do front-end: HTML, CSS e JavaScript. O objetivo principal deste projeto foi criar uma interface limpa e funcional, demonstrando minhas habilidades na estruturação de páginas web, estilização e interação básica com o usuário.
Como foi construído?
 * HTML: A estrutura da página foi criada utilizando HTML5, com foco na semântica para garantir acessibilidade e organização do conteúdo (barra de pesquisa, botões).
 * CSS: O estilo visual foi implementado com CSS puro, buscando replicar a aparência simples e direta da página de busca do Google, com foco na responsividade para diferentes dispositivos.
 * JavaScript: O JavaScript foi utilizado para adicionar a interatividade básica, permitindo que ao digitar um termo na barra de pesquisa e clicar no botão "Pesquisa Google" (ou pressionar Enter), o usuário seja redirecionado para a página de resultados do Google com a sua consulta. O botão "Estou com sorte" também foi implementado para direcionar o usuário diretamente para o primeiro resultado da pesquisa (ou para os Doodles do Google caso nenhum termo seja digitado).
Por que este projeto?
Este projeto serviu como um excelente exercício prático para consolidar meus conhecimentos em HTML, CSS e JavaScript, além de demonstrar minha capacidade de criar interfaces web funcionais e intuitivas. Embora seja uma versão simplificada, ela ilustra os conceitos chave do desenvolvimento front-end.
